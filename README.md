# Opelika 2029 (web demo)

A browser test of the small-town game idea, built on real downtown Opelika, Alabama map data.

- Play: visit the Vercel link, or open `index.html` in a browser.
- iPhone: open the link in Safari, tap Share → Add to Home Screen, and play sideways.
- Controllers: PS4, PS5, Xbox and most Bluetooth controllers work.
- Settings (gear button): floating stick, push-to-run, button size, left-handed layout, tilt steering, graphics.
- Map data © OpenStreetMap contributors.

This is a prototype. The real game is being built in Unity.
